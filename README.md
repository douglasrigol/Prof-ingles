# Site-prof-de-ingles
Landing page fictícia de uma professora de inglês, pensada para converter visitantes em contatos. Tem menu responsivo, carrossel de depoimentos, perguntas frequentes em acordeão e botões de contato bem destacados. Projeto de portfólio, sem cliente real.
